A plain save by each Android program: the file opened, one entry `droid-added` added at the root,
the database saved, and the file read back.

A block is one file as `Kpg.cs` read it with KeePassLib 2.61.1, less the work directory in front of
its path. Its first line is the summary: the file, the KDBX version, then each of the plugin's keys
as label:value/time. A value is `=` where C and P hold the same and this file holds it, `C` or `P`
for that copy's, and the whole item is `label:-` where the key is absent. A time is `=`, `C` or `P`
the same way and `none` where the key has no modification time. `G:` and `E1:` are the rule on that
group and that entry: `C`, `P`, or `-` for none. `E2@H(prev)` is an entry in H whose previous parent
group is still recorded. Under it: the bytes, the KDF, each key with its value cut at 40 characters
and its time after `@`, then every group and entry with its modification time, its previous parent
and its custom data.

Every file is P. `P-plain-fast` and `P-moved-fast` are Argon2d with rules on G and E1, and in the
second E2 has been moved to H. `P-plain-aes` is the first with AES-KDF. A name ending in `b` has no
rule on any group or entry. The Keepass2Android 1.15-r6 files were read back before the reader
printed `SettingsChanged`.

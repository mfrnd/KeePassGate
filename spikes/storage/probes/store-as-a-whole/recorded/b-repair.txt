== B.6: the repair after a Synchronize at a gate. Each history ends with KeePass's
   Synchronize at gate 0. Modes: the repair written inside the save, and the merged
   database then written to the other file as well (as KeePass writes both; read, not run);
   the same with the other file written before the repair; and no repair (the control).
   Added from the desktop measurement: a Synchronize with the trigger system off is announced
   to no plugin, so it is the mode "no repair, both files"; a repair made at the save's own
   event is the mode "repair, both files". File, Import raises no event: the same merge as an
   import with each method, the open file only, without the repair and with the repair made
   at the person's next save against the state the plugin held before.
